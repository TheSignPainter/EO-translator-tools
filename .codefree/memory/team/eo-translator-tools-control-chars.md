EO 系列汉化工具的控制字符↔可读文本转换规则（readme.md 与 single_parser.py 声明，修改解析逻辑时必须遵守）：{f859}{xxxx}→[[speaker: 角色名]]（匹配主角团姓名，其余保留原格式）；{f804}→[[文字？起始]]；{f813}+4个hex→[[voice: ...]]；{f855}+2个hex→[[portrait: ...]]；{f843}→[[member: ...]]；换行符 {f801} 转为 [[换行]] 保留原换行位置，回填时自动还原，可增删 [[换行]] 调整换行位置；换页符 {f801}{f802}→[[下一页]]（换页符前必定有 {f801}，不要写成 [[换行]][[下一页]]）；在 [[speaker]] 与 [[下一页]] 等控制字符后附加 \n 便于阅读。EO5 特有 {f81b}...{0000} 声音控制字符：固定头部 {f81b}{565f}{4348}{4152}{5f31}（位置1-5 全量统计 100% 一致），位置6（0-based 5）与说话人强相关（3031→洁涅塔、3032→梅莉娜、3033→埃德加、3034→瑟里克、3035→雷穆斯、3036→莉莉、3037→索罗尔、3039→阿尔空），其中 3038 同时对应卫兵/城市传令官无法仅凭位置6判定，必须依靠行内最近 {f859}{xxxx}，行内无 {f859} 时显示"角色3038"。回填校验规则：回填后每行不得超过 22 个字符，超出需手动在合适位置插入 [[换行]]；回填结果不得残留 [[ 或 ]]；换页符前必须有标点（校验尚未实现）；revert 仅在行尾为普通文本时补充 {f801}，以控制字符/占位符结尾时不再追加，保证 source 无损往返。
